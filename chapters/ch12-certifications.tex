\chapter{美国证券从业资格考试指南}

本章覆盖 FINRA 旗下的核心证券从业资格考试：SIE、Series 7、Series 57、Series 65、Series 24。这些考试是进入美国证券行业的关键门槛，也是量化金融从业者了解监管框架和业务规则的重要参考。

\section{SIE：证券行业基础考试}

\subsection{考试概述}

\textbf{Securities Industry Essentials (SIE)} 是 FINRA 设立的基础入门考试，对所有意向进入证券行业的人员开放，无需雇主担保。

\begin{table}[h]
\centering
\caption{SIE 考试基本信息}
\begin{tabular}{@{}ll@{}}
\toprule
项目 & 详情 \\
\midrule
题目数量 & 75 题（另含 10 题不计分预测试题） \\
考试时长 & 1 小时 45 分钟 \\
通过分数 & 70\% \\
考试费用 & \$80 \\
有效期 & 4 年 \\
\bottomrule
\end{tabular}
\end{table}

\subsection{知识领域}

\begin{enumerate}[leftmargin=*]
  \item \textbf{资本市场知识 (16\%)}
  \begin{itemize}
    \item 监管机构和职能：SEC、FINRA、MSRB、美联储
    \item 市场结构：一级/二级市场、交易所、ATS/暗池
    \item 经济因素：货币政策（联邦基金利率、贴现率、公开市场操作）、财政政策
  \end{itemize}

  \item \textbf{产品理解 (44\%)}
  \begin{itemize}
    \item 权益证券：普通股 vs 优先股，ADR，认股权证
    \item 债务工具：国债、市政债（GO vs Revenue）、公司债（可转债、可回售债）
    \item 市政债券：免税特性，MSRB 规则
    \item 打包产品：共同基金、ETF、封闭式基金、REITs、对冲基金
    \item 期权基础：Call/Put 定义，内在价值 vs 时间价值
    \item 年金：固定 vs 可变，即期 vs 递延
    \item 风险：系统性风险 vs 非系统性风险，通胀/利率/信用/流动性/货币风险
  \end{itemize}

  \item \textbf{交易、客户账户与禁止行为 (31\%)}
  \begin{itemize}
    \item 账户类型：现金账户 vs 保证金账户
    \item 订单类型：市价单、限价单、止损单
    \item 结算周期：T+1（2024 年 5 月起）
    \item KYC 规则、Suitability 适合性义务
    \item 内幕交易（1934 法案 10b-5 规则）
    \item 反洗钱 (AML)：USA PATRIOT Act
  \end{itemize}

  \item \textbf{监管框架 (9\%)}
  \begin{itemize}
    \item 1933 证券法（新发行注册）
    \item 1934 证券交易法（二级市场监管、SEC 设立）
    \item 1940 投资公司法（基金监管）
    \item 1940 投资顾问法（投顾监管）
  \end{itemize}
\end{enumerate}

\section{Series 7：通用证券代表}

\subsection{考试概述}

Series 7 (General Securities Representative, GS) 是注册代表的旗舰考试。通过后可交易几乎所有证券产品。

\begin{table}[h]
\centering
\caption{Series 7 考试基本信息}
\begin{tabular}{@{}ll@{}}
\toprule
项目 & 详情 \\
\midrule
题目数量 & 125 题（另含 10 题预测试题） \\
考试时长 & 3 小时 45 分钟 \\
通过分数 & 72\% \\
前置条件 & 通过 SIE \\
雇主担保 & 需要 \\
\bottomrule
\end{tabular}
\end{table}

\subsection{核心知识领域}

\begin{enumerate}[leftmargin=*]
  \item \textbf{为客户寻求业务 (31\%)}
  \begin{itemize}
    \item 客户画像：投资目标、风险承受力、时间范围、流动性需求
    \item 税务考量：资本利得（短期 vs 长期）、成本基础计算（FIFO/LIFO/特定识别）
    \item 退休计划：IRA（传统/Roth）、401(k)、403(b)、SEP、SIMPLE
    \item 教育储蓄：529 计划、Coverdell ESA
  \end{itemize}

  \item \textbf{评估客户财务画像和风险 (68 题)}
  \begin{itemize}
    \item \textbf{企业证券}：普通/优先股、权利 (Rights)、认股权证
    \item \textbf{市政证券}：GO/Revenue 债券、MSRB 规则、债券分析（名义收益/当前收益/YTM/YTC）
    \item \textbf{美国政府证券}：T-Bills（零息）、T-Notes、T-Bonds、TIPS、STRIPS
    \item \textbf{公司债券}：抵押债券、信用债券、可转换债券
    \item \textbf{打包产品}：共同基金（费率结构、12b-1 费）、可变年金、ETF
    \item \textbf{期权策略}：Covered Call、Protective Put、Straddle、Spread、Collar
    \item \textbf{保证金账户}：Regulation T（初始保证金 50\%）、维持保证金要求（25\% 多头）
    \item \textbf{期权保证金}：裸卖期权的高保证金要求
  \end{itemize}

  \item \textbf{开盘、维护与关闭客户账户 (18\%)}
  \begin{itemize}
    \item 新账户文档：客户协议、W-9、风险披露
    \item 客户确认和账户对账单
    \item 投诉处理和记录保存
  \end{itemize}

  \item \textbf{获取并验证客户买卖指示 (17\%)}
  \begin{itemize}
    \item 交易执行：做市商报价、最佳执行义务
    \item 订单处理：Regulation NMS（全国市场系统）
    \item 交易报告：TRACE（公司债）、MSRB（市政债）
  \end{itemize}
\end{enumerate}

\subsection{期权重点}

Series 7 考试中期权占比很高（约 30-35 题），重点包括：
\begin{itemize}[leftmargin=*]
  \item 收益图绘制和盈亏平衡计算
  \item 基本策略：Long/Short Call/Put，Covered Call，Protective Put
  \item 差价策略：Bull/Bear Spread（Call/Put）、Butterfly、Calendar Spread
  \item 组合策略：Straddle（Long/Short）、Strangle
  \item 对冲与收益计算
  \item 保证金计算
\end{itemize}

\section{Series 57：证券交易员}

\subsection{考试概述}

Series 57 (Securities Trader) 针对股票、公司债券和市政债券交易员。

\begin{itemize}[leftmargin=*]
  \item 题目数量：50 题（另含 5 题预测试题）
  \item 考试时长：1 小时 45 分钟
  \item 通过分数：70\%
\end{itemize}

\subsection{核心知识领域}

\begin{enumerate}[leftmargin=*]
  \item \textbf{交易活动与禁止行为 (58\%)}
  \begin{itemize}
    \item 做市义务与报价规则
    \item 交易操纵：Wash Sales（洗售）、Matched Orders、Painting the Tape、Spoofing/Layering
    \item 内幕交易与 MNPI（重大非公开信息）
    \item 最佳执行义务
    \item 前端运行 (Front Running) 禁止
    \item 净资本规则 (Net Capital Rule, SEC Rule 15c3-1)
  \end{itemize}

  \item \textbf{订单处理与交易报告 (26\%)}
  \begin{itemize}
    \item OATS（订单审计追踪系统 $\to$ CAT 替代中）
    \item 大额交易报告
    \item 场外交易处理
  \end{itemize}

  \item \textbf{一般证券知识与监管 (16\%)}
  \begin{itemize}
    \item 监管机构角色
    \item 记录保存要求
    \item 反洗钱 (AML) 和 OFAC 制裁合规
  \end{itemize}
\end{enumerate}

\section{Series 65：统一投资顾问法律考试}

\subsection{考试概述}

Series 65 (Uniform Investment Adviser Law Examination) 是成为注册投资顾问 (RIA/IAR) 的代表性资格。

\begin{itemize}[leftmargin=*]
  \item 题目数量：130 题（另含 10 题预测试题）
  \item 考试时长：3 小时
  \item 通过分数：72\%（130 题中正确 94 题）
\end{itemize}

\subsection{核心知识领域}

\begin{enumerate}[leftmargin=*]
  \item \textbf{经济因素与商业信息 (15\%)}
  \begin{itemize}
    \item 经济周期（扩张/顶峰/收缩/谷底）
    \item 先行/同步/滞后指标
    \item 货币政策（联邦基金利率、贴现率、准备金要求、公开市场操作）
    \item 收益率曲线分析（正常的/平坦的/倒挂的）
    \item 商业周期 vs 部门轮动
  \end{itemize}

  \item \textbf{投资工具特性 (25\%)}
  \begin{itemize}
    \item 现金与等价物特征
    \item 固定收益：评级（Moody's/S\&P/Fitch）、久期、凸性
    \item 权益估值：DCF、P/E、P/B、PEG、股利贴现模型
    \item 共同基金费用：12b-1 费、前端/后端手续费、管理费
    \item 衍生品（有限范围）
    \item 另类投资（私募股权、对冲基金、VC）
    \item 保险产品：终身寿险、万能寿险、可变寿险
  \end{itemize}

  \item \textbf{客户投资建议与策略 (30\%)}
  \begin{itemize}
    \item 客户画像：投资目标、财务状况、风险承受力、时间范围
    \item 资产配置：战略 vs 战术配置
    \item 现代投资组合理论 (MPT)：有效前沿、相关性与分散化
    \item CAPM：$\beta$，证券市场线 (SML)
    \item 风险度量：标准差、$\beta$、夏普比率、Alpha
    \item 投资风格：价值 vs 成长，大盘 vs 小盘
    \item 退休规划：IRA 传统/Roth，401(k)，其他合格计划
    \item 教育规划工具
    \item 保险规划建议
  \end{itemize}

  \item \textbf{法律、法规与指南 (30\%)}
  \begin{itemize}
    \item \textbf{Uniform Securities Act (USA)} —— 各州证券监管的基础
    \item 1940 投资顾问法：受托义务、注册要求、禁止行为
    \item 受托标准 vs 适合性标准
    \item 广告与营销规则
    \item 费用披露与客户沟通要求
    \item 账簿与记录要求
    \item NASAA 示范规则（道德准则、托管规则）
  \end{itemize}
\end{enumerate}

\begin{keybox}
Series 65 的核心哲学：投资顾问对客户承担\textbf{受托责任 (Fiduciary Duty)}——始终以客户最佳利益行事，这是与经纪交易商（Suitability 标准）的根本区别。
\end{keybox}

\section{Series 24：通用证券负责人}

\subsection{考试概述}

Series 24 (General Securities Principal) 是管理级别资格考试，面向负责监督经纪自营商业务的高管。

\begin{itemize}[leftmargin=*]
  \item 题目数量：150 题（另含 10 题预测试题）
  \item 考试时长：3 小时 45 分钟
  \item 通过分数：70\%
\end{itemize}

\subsection{核心知识领域}

\begin{enumerate}[leftmargin=*]
  \item \textbf{投资银行与研究监管 (24\%)}
  \begin{itemize}
    \item 承销类型：包销 (Firm Commitment) vs 代销 (Best Efforts)
    \item 注册流程：1933 法案登记声明、招股说明书
    \item 尽职调查义务
    \item 研究分析师规则：研究报告与投资银行部门的隔离
    \item 安静期 (Quiet Period)
    \item Global Research Analyst Settlement
  \end{itemize}

  \item \textbf{交易与做市监管 (19\%)}
  \begin{itemize}
    \item 做市商义务
    \item 卖空规则 (Regulation SHO)
    \item 大宗交易报告
    \item 异常交易报告
  \end{itemize}

  \item \textbf{客户账户与销售实践监管 (29\%)}
  \begin{itemize}
    \item 账户审批与监督
    \item 适合性规则 (Suitability)
    \item 反洗钱 (AML) 合规计划
    \item 隐私规则 (Regulation S-P)
    \item 客户投诉处理
    \item 老年人财务剥削报告
  \end{itemize}

  \item \textbf{运营与财务监管 (28\%)}
  \begin{itemize}
    \item 净资本规则 (Net Capital Rule, 15c3-1)
    \item 客户保护规则 (Customer Protection Rule, 15c3-3)
    \item 记录保存要求 (17a-3, 17a-4)
    \item 财务报告：FOCUS 报告
    \item 年度审计要求
    \item 业务连续性计划 (BCP)
    \item 网络安全要求
  \end{itemize}
\end{enumerate}

\section{量化金融从业者的视角}

对量化金融从业者而言，这些考试的价值不在于知识深度——量化人员的数学和编程能力远超考试要求——而在于：

\begin{enumerate}[leftmargin=*]
  \item \textbf{监管合规框架}：理解 SEC、FINRA、MSRB 的监管结构，避免触碰合规红线
  \item \textbf{产品广度}：覆盖量化策略可能交易的各类证券和衍生品
  \item \textbf{职业道德}：受托责任、适合性、禁止行为——这些比技术能力更难量化但同样重要
  \item \textbf{职业许可}：具备从业资格可以合法地与客户互动和提供建议
\end{enumerate}

\section{小结}

SIE $\to$ Series 7 $\to$ Series 57/65/24 构成了一条从入门到高级的证券从业资格路径。对量化金融从业者，即使不需要全部考取，理解这些考试覆盖的知识框架——从产品特性到监管结构、从职业道德到运营规则——也是在高度受监管的金融行业中安全航行的必要条件。

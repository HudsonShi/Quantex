## 1. 内容要求（这一节决定「丰富」的程度）

### 1.1 总目标

把原来「提纲式、每章约 200 行」的章节，扩写为「教材式、每章 380--560 行」的章节，做到
**公式—直觉—应用—风险四件套齐全**。原有内容必须保留其知识要点（可以重组、改写、
纠正错误、补充推导），不得简单删减。

### 1.2 每章最低配额

| 项目 | 最低要求 |
|---|---|
| 总行数 | ≥ 380 行（数学重的章争取 450+） |
| 公式环境（`equation`/`align`） | 新增 ≥ 8 个，且关键结论必须有推导或来源说明 |
| 图（TikZ / pgfplots） | ≥ 2 张，必须能直观说明一个金融概念 |
| 表格（booktabs） | ≥ 3 张（对比类、清单类、数值类） |
| 代码示例（`lstlisting`） | ≥ 1 段可运行代码（第 12 章可例外） |
| 交叉引用 `\cref` | ≥ 5 处，指向本章内的公式/图/表/定义 |
| `keybox` | ≥ 2 个（每节最多 1 个，不要滥用） |
| `appbox` / `intuitionbox` / `warningbox` / `notebox` | 合计 ≥ 3 个 |
| `definition` / `example` / `theorem` | 合计 ≥ 3 个，其中至少 1 个带具体数值的算例 |
| 章末三件套 | `summarybox` + `exercises` + `furtherreading` 必须有 |

### 1.3 写作质量标准

- **不要把结论写成口号**。出现「非常重要」「极其关键」这类形容词时，必须紧跟一个具体理由或数字。
- **每个重要公式都要有变量说明**（用「其中 $x$ 为……」句式）。
- **尽量给出数量级直觉**。例如：「$\alpha+\beta=0.98$ 意味着波动率冲击的半衰期约为 34 天」。
- **必须写失效条件**。凡是有名有姓的模型（BSM、GARCH、Markowitz、VaR、Copula），
  都要说明它在哪里会出错，用 `warningbox` 或正文段落写清楚。
- **数字要真实可核查**，不确定的历史数字宁可写「约」或换成定性描述，禁止编造精确统计。
- 中英混排时，**中文与行内公式/英文缩写之间加一个空格**：`用 $\Sigma^{-1}$ 计算` 、`采用 GARCH 模型`。
- 使用中文全角标点（，。；：？！），引号统一用中文弯引号 “ ” 和 ‘ ’，不要用 `"`。
- 百分号写 `\%`；不要出现 `$100%$` 这类写法，写成 `100\%`。
- 行文用书面语，避免口语与网络用语。

## 2. 数学与符号约定

### 2.1 已提供的数学宏（请优先使用，确保全书一致）

| 宏 | 结果 | 用途 |
|---|---|---|
| `\E` | 𝔼 | 期望 |
| `\Prob` / `\Qm` | ℙ / ℚ | 真实测度 / 风险中性测度 |
| `\Fm` | ℱ | 信息流 |
| `\N` / `\R` | 𝒩 / ℝ | 正态分布族 / 实数集 |
| `\Var` `\Cov` `\Corr` `\sd` `\se` | Var Cov Corr sd SE | 统计量 |
| `\VaR` `\ES` | VaR ES | 风险度量 |
| `\abs{x}` `\norm{x}` `\inner{x}{y}` | ∣x∣ ‖x‖ ⟨x,y⟩ | 绝对值/范数/内积 |
| `\dd` `\ee` `\ii` | d e i | 微分、自然指数、虚数单位（正体） |
| `\ind{A}` | 𝟙_{A} | 示性函数 |
| `\tr` `\diag` `\rank` `\supp` `\sign` | tr diag rank supp sgn | 算子 |
| `\vect{w}` `\muvec` `\Sigmamat` | **w** μ Σ | 向量/矩阵粗体 |
| `\pd{f}{x}` `\pdd{f}{x}` | ∂f/∂x ∂²f/∂x² | 偏导 |
| `\argmax` `\argmin` | arg max / arg min | 下标算子 |

### 2.2 符号一致性要求

- 资产价格 `S_t`、行权价 `K`、到期 `T`、利率 `r`、波动率 `\sigma`、权重 `w`；
- 测度期望必须写清上标：`\E^{\Qm}[\cdot]` 与 `\E^{\Prob}[\cdot]` 不可混用；
- 微分用 `\dd`（正体 d），例如 `\dd S_t = \mu S_t\,\dd t + \sigma S_t\,\dd W_t`；
- 公式环境：单个公式用 `equation`，多行对齐用 `align`（用 `&=` 对齐）。**禁止 `eqnarray`**；
- 公式后的标点：中文句子中的公式行末**不要加逗号或句号**（`equation` 环境自带间距），
  如果公式是句子的一部分，用 `\begin{equation} ... \end{equation}` 单独成行即可；
- 标题（`\section`/`\subsection`）中**禁止出现数学模式 `$...$`**，否则 PDF 书签会报警。
  写成「AR(p) 模型」「学生 t 分布」这样（用普通文字，不加 `$`）。
